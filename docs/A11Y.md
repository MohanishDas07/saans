# SAANS Accessibility (A11Y) Audit & Compliance

Target Standard: **WCAG 2.2 Level AA**

---

## 1. Compliance Checklist

- [x] **Semantic HTML & Landmarks:** All pages use `<header>`, `<nav>`, `<main id="main-content">`, `<section>`, `<article>`, and `<footer>`.
- [x] **Skip Link:** Accessible `.skip-to-content` link positioned first in DOM.
- [x] **Focus Visible:** All interactive elements feature high-contrast visible focus rings (`:focus-visible`).
- [x] **Color Not Sole Communicator:** AQI is never communicated solely by color; always paired with explicit text label (Good, Satisfactory, Moderate, Poor, Very Poor, Severe), numeric AQI value, and particulate concentration.
- [x] **Contrast Compliance:** All core tokens verified against WCAG AA/AAA standards (minimum 4.5:1 for body text, 3:1 for large display headers).
  - Ink (`#17181A`) on Paper (`#F3EFE6`): **15.5:1** (Passes WCAG AAA).
  - Ink Muted (`#4A4D52`) on Paper (`#F3EFE6`): **7.4:1** (Passes WCAG AAA).
  - CPCB Severe (`#7A0F2E`) with white text: **10.9:1** (Passes WCAG AAA).
- [x] **Prefers-Reduced-Motion:** The signature SVG city skyline transitions and animations respect user reduced-motion OS preferences.
- [x] **Elder Mode:** Opt-in toggle raising base font size to $19\,\text{px}$, line height to $1.75$, and minimum touch target size to $52\,\text{px}$.
- [x] **Screen-Reader Support:** Decorative skyline is tagged `aria-hidden="true"`; live incoming assistant responses use an `aria-live="polite"` region (`role="log"`) in the chat interface; printable bulletins are encapsulated in accessible `<article>` landmarks.
- [x] **Multilingual Typography:** Correct `lang` attributes set dynamically (`en`, `hi`, `mr`) for proper screen reader pronunciation and Devanagari font rendering.
